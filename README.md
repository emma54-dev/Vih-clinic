# VIH Clínico

**Guía interactiva educativa para estudiantes de medicina** sobre
identificación, orientación diagnóstica, vinculación a atención y
seguimiento de personas con VIH.

## Publicar con GitHub Pages

### 1. Crear un repositorio

1.  Inicia sesión en [GitHub](https://github.com/).
2.  Selecciona **New repository**.
3.  Usa un nombre como `vih-clinico`.
4.  Elige **Public** si quieres que la página sea accesible públicamente
    y crea el repositorio.

### 2. Subir los archivos

1.  Abre el repositorio y selecciona **Add file → Upload files**.
2.  Sube `index.html` y `README.md`.
3.  Confirma con **Commit changes**.

**Importante:** coloca `index.html` en la raíz del repositorio, no
dentro de una subcarpeta.

### 3. Activar GitHub Pages

1.  En el repositorio, abre **Settings → Pages**.
2.  En **Build and deployment**, selecciona **Deploy from a branch**.
3.  Elige la rama `main` y la carpeta `/(root)`.
4.  Pulsa **Save** y espera a que finalice la publicación.
5.  La dirección aparecerá en la sección Pages. Normalmente tendrá este
    formato: `https://TU-USUARIO.github.io/vih-clinico/`.

Sustituye `TU-USUARIO` y `vih-clinico` por tu usuario y el nombre real
del repositorio. La URL definitiva la proporciona GitHub.

Documentación oficial: [Configurar GitHub
Pages](https://docs.github.com/es/pages/quickstart).

## ¿Qué incluye?

-   **Inicio y ruta de atención:** pasos generales desde la acogida
    hasta el seguimiento.
-   **Detección y exposición:** práctica de valoración inicial,
    consentimiento y privacidad.
-   **Algoritmo diagnóstico:** orientación general para interpretar
    resultados de tamizaje.
-   **Primeros pasos:** lista de comprobación para la vinculación a
    atención integral.
-   **Seguimiento:** recordatorios académicos sobre carga viral, CD4,
    tratamiento antirretroviral (TAR), adherencia y otros aspectos de
    salud.
-   **Caso de práctica:** preguntas con retroalimentación para
    estudiantes.
-   **Fuentes y límites:** referencias y recordatorios para verificar la
    normativa vigente.
-   Diseño adaptable a computadora, tableta y teléfono.
-   Opción para imprimir o guardar como PDF algunas secciones.

## Privacidad y almacenamiento

La página es un archivo HTML estático. El código no envía los campos del
formulario a un servidor ni crea un expediente clínico. Los datos
ingresados se reinician al recargar la página.

**No introduzcas nombres, CURP, teléfonos, direcciones ni otros datos
identificables de pacientes.** Usa únicamente información ficticia o
desidentificada para ejercicios académicos. Al publicarla con GitHub
Pages, la página será accesible públicamente si el repositorio y la
configuración así lo permiten. No debe utilizarse para guardar
información clínica confidencial.

## Advertencia clínica

Este recurso es exclusivamente educativo. No sustituye la valoración de
profesionales responsables, los algoritmos aprobados por el laboratorio,
las guías clínicas vigentes ni los protocolos institucionales o
nacionales.

La página menciona que el manual mexicano de vigilancia usado como
referencia corresponde a **2012**; no debe asumirse que representa la
normativa actual. Antes de utilizar el contenido en un entorno clínico,
verifica las recomendaciones más recientes con las autoridades
sanitarias y el servicio especializado en VIH. La evaluación de
profilaxis posexposición (PEP), las pruebas, la confirmación
diagnóstica, el tratamiento y el seguimiento deben ajustarse a las
indicaciones vigentes.
